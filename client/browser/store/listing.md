# Store listing texts: oneq mesh

Used for the forms of the Chrome Web Store, Microsoft Edge Add-ons and addons.mozilla.org. Edit the contact and the homepage before submitting.

## Name
oneq mesh

## Summary (Chrome limit 132 characters)
Open your oneq post-quantum mesh in the browser: only mesh addresses and *.oneq names use the local oneq proxy.

## Description
oneq mesh connects your browser to a oneq mesh (a private, post-quantum encrypted network between your own computers) without a VPN driver and without administrator rights.

How it works: `oneqclient proxy` runs on your computer, joins the mesh like any other node and offers a SOCKS5 proxy on 127.0.0.1. This extension sends only the addresses of
your mesh and names ending in `.oneq` through that proxy; everything else the browser does is left alone. The toolbar icon shows the state of the connection and the popup lists the
members of the mesh and whether each one is reached directly or through a relay.

You need the oneq client installed on the same computer (it provides the connection manager the extension talks to). The extension does nothing without it.

* Opens mesh hosts by address (http://10.x.y.z/) or by member name (http://name.oneq/).
* A switch gives the browser's proxy settings back at any time.
* The proxy serves browsers only: other programs on the computer are refused by default.
* No account, no tracking, no data leaves your computer; the extension talks only to 127.0.0.1.

oneq is an educational project without an independent security audit.

## Single purpose (Chrome Web Store)
Route requests for the user's oneq mesh (its private addresses and *.oneq names) through the user's local oneq SOCKS5 proxy and show the state of that proxy.

## Permission justifications
| Permission | Why |
|---|---|
| `proxy` | Chromium: sets a PAC script that sends only the mesh addresses and *.oneq names to the local SOCKS5 proxy. Firefox: `proxy.onRequest`, the same decision per request. |
| `storage` | Keeps the extension's settings (proxy and status address, extra networks, on/off) in local storage. |
| `nativeMessaging` | Talks to the oneq connection manager (`oneqclient native-host`) installed on the user's computer: it keeps the connection settings and starts and stops the local oneq proxy. Nothing is sent to any server. |
| `alarms` | Wakes the background script every 30 seconds to refresh the status badge and keep the proxy settings in line with the running proxy. |
| `http://127.0.0.1/*`, `http://localhost/*` | Reads the status page of the local proxy (`/status`). |
| `<all_urls>` (Firefox only) | Firefox lets `proxy.onRequest` act only on hosts the extension has permission for, and the mesh addresses are not known in advance. The listener returns "direct" for everything outside the mesh and never reads page content. |

No remote code is loaded; the content security policy allows scripts from the extension package only.
