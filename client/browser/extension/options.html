oneq mesh

Connection

The password goes to the oneq connection manager on this computer (oneqclient native-host), which keeps it in a file only you can read; the extension does not store it. The settings file is the one the oneq apps export (Settings, Export).

Advanced

Only addresses of the mesh (read from the running proxy) and names ending in .oneq use the proxy; everything else is not touched. Both addresses must be on this computer (127.x.x.x or localhost).
